## 🌟 عن المشروع (Project Overview)

**منصة رحلة داعية (Rihlat Da'eyah)** هي منصة تعليمية وتربوية متكاملة مصممة لإدارة الدفعات القرآنية والحلقات والأندية التخصصية. تهدف المنصة إلى تحفيز الطلاب والطالبات على حفظ القرآن الكريم والمواظبة على التحديات الإيمانية والتربوية من خلال **نظام التلعيب (Gamification)** المستند إلى النقاط، الأوسمة، الشارات الإيمانية، ورتب "رحلة الداعية".

تتيح المنصة للمعلمات والمشرفات المتابعة المباشرة للطلاب، مراجعة التسليمات والأنشطة، إرسال الرسائل والتنبيهات الموجهة (حسب الطالب أو الفصل أو النادي أو الدفعة)، وإدارة المكتبة التعليمية التفاعلية.

## 🚀 المميزات والوحدات الرئيسية (Core Modules & Features)

### 1. 🎓 بوابة الطالبة / الشباب (Student Portal)
- **شريط المحطات الإيمانية (Journey Stations Bar)**: تتبع تقدم الطالبة عبر رتب الرحلة (🌱 البداية ⬅️ 📖 طالب علم ⬅️ ⭐ مجتهد ⬅️ 💎 متميز 🌟 👑 قدوة).
- **قائمة التحديات المباشرة (Live Challenges)**: تحديات يومية وأسبوعية وشهرية تفاعلية تعتمد على النقاط (XP) ونسبة الإنجاز الحقيقية.
- **الأندية الطلابية التخصصية (Student Clubs)**: الانضمام لأندية النشاط (مثل نادي الإذاعة، نادي القرّاء، نادي التكنولوجيا) والتفاعل مع مهام وإعلانات النادي.
- **المكتبة الرقمية (Digital Library)**: استعراض الملفات التعليمية (PDF، صوت، فيديو، مستندات، روابط) الموجهة للطالبة بحسب الدفعة أو الفصل أو النادي.
- **لوحة رسائل المعلمة (Teacher Direct Messages)**: استقبال الرسائل والإعلانات المباشرة من المشرفة مع خاصية تأكيد القراءة.
- **لوحة الأوسمة والإنجازات (Achievements & Badges)**: استعراض الأوسمة المحررة والمعتمدة تلقائياً أو بعد مراجعة المعلمة.

### 2. 👩‍🏫 بوابة المعلمة / المشرفة (Supervisor / Teacher Dashboard)
- **إدارة الدفعات والفصول (Batches & Classes)**: إنشاء الدفعات، تقسيم الفصول الدراسية، توزيع الطلاب، ومتابعة المتوسطات والإحصائيات.
- **إدارة الأندية التخصصية (Club Management)**: إنشاء الأندية، تعيين المشرفين، إضافة الأعضاء، وتكليف المهام.
- **نظام المراجعة والاعتماد (Submissions Review Engine)**: استقبال تسليمات الطلاب للتحديات والمهام، المراجعة، إضافة الملاحظات والثناء، واعتماد النقاط تلقائياً.
- **الرسائل والإعلانات الموجهة (Targeted Messaging System)**: إرسال رسائل موجهة لطالب معين، أو فصل محدد، أو نادي خاص، أو للدفعة بالكامل مع متابعة إيصالات القراءة (`readBy`).
- **المكتبة التفاعلية (Library Management)**: رفع وتوجيه الوسائط والمستندات التعليمية.
- **إعدادات النظام الشاملة (System Settings)**: تخصيص محطات الرحلة، مضاعفات XP، الهوية البصرية، وقوالب الإشعارات.

## 🛠️ الهيكل التقني ونظام البيانات (Tech Stack & Architecture)

- **واجهة المستخدم (Frontend Framework)**: React 18+ + TypeScript
- **أداة البناء (Build Tool)**: Vite
- **التنسيق والأنماط (Styling)**: Tailwind CSS v4
- **الحركات والتحريك (Animations)**: Motion (`motion/react`)
- **الأيقونات (Icons)**: Lucide React
- **قاعدة البيانات وقوة المزامنة (Data Persistence & Sync)**:
  - محرك تخزين استجابي محلي (`LocalStorage Sync Engine`) مع أحداث `CustomEvent('rihlat_db_updated')`.
  - تكامل اختياري مع **Supabase JS Client** للنسخ الاحتياطي والمزامنة السحابية.
- **توليد المستندات (PDF Generation)**: `pdfkit`

## 👥 شرح أدوار المستعملين (User Roles & Portals)

### 1. وضع الطالبة (Student Mode)
تستطيع الطالبة الوصول إلى:
1. **الرئيسية**: استعراض محطات الرحلة والإحصائيات الشخصية ورسائل المعلمة المباشرة.
2. **التحديات**: حل التحديات اليومية والأسبوعية والشهرية وتقديم الإجابات للمراجعة.
3. **الأندية**: تصفح النادي المنضمة إليه وإنجاز مهام النادي.
4. **المكتبة**: تحميل ومطالعة الملفات التعليمية المصنفة.
5. **الأوسمة**: متابعة الأوسمة المحررة والمطلوبة.

### 2. وضع المعلمة / المشرفة (Teacher / Supervisor Mode)
تستطيع المشرفة التنقل بين الدفعات وإدارة:
1. **الطلاب والفصول**: إضافة تعديل وتتبع مستويات الطلاب.
2. **الرسائل الإعلانات**: إرسال رسائل موجهة وتتبع من قرأ الرسالة.
3. **الطلبات والتسليمات**: مراجعة الإجابات، قبولها مع منح XP، أو رفضها مع ملاحظة للتعديل.
4. **إعدادات المنظومة**: تعديل معايير محطات الترقية ونسب النقاط والمشرفين.

## 💻 دليل التشغيل والتطوير (Installation & Setup Guide)

### 1. المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### 2. خطوات التثبيت والتشغيل المحلي
```bash
# 1. استنساخ المشروع أو الدخول للمجلد
cd rihlat-daeyah

# 2. تثبيت الحزم المطلوبة
npm install

# 3. تشغيل خادم التطوير (Port 3000)
npm run dev

# 4. التجميع للإنتاج (Production Build)
npm run build

# 5. الفحص اللغوي والنحوي (Linting)
npm run lint
```

## ⚙️ إعدادات النظام والبيئة (Environment & Customizations)

يمكن ربط قاعدة البيانات السحابية برفع متغيرة البيئة التالية في `.env`:
```env
VITE_SUPABASE_URL=https://your-supabase-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

وفي حالة عدم وجود المتغيرات، يعمل النظام تلقائياً وبكفاءة 100% باستخدام **نظام التخزين التفاعلي المحلي (Reactive Local Storage Store)** مع إمكانية المزامنة والتصدير في أي وقت.
